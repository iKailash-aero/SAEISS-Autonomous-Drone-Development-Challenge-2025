# SAEISS Autonomous Drone Development Challenge 2025

## Project Overview

This project focuses on the design, development, and autonomous operation of a multirotor UAV capable of QR-code scanning and precision payload delivery. The UAV was developed to autonomously navigate to designated waypoints, scan QR codes using onboard vision systems, transmit data to the ground station, and accurately deploy payloads at specified locations.

## Objectives

* Design and develop an autonomous quadcopter for payload delivery missions
* Integrate QR-code scanning capability using onboard vision systems
* Perform UAV sizing and propulsion system selection
* Design and develop an efficient payload dropping mechanism
* Conduct CFD analysis to evaluate aerodynamic characteristics
* Implement autonomous navigation and mission planning
* Ensure stable and reliable flight performance

* Configuration: Quadcopter
* Maximum Take-Off Weight: 2 kg
* Payload Capacity: 320 g
* Propeller Size: 10 × 4.5 inch
* Flight Controller: Pixhawk Cube Orange
* GPS Module: Here 3+
* Communication System: SkyDroid T10
* Battery: 5200 mAh 4S LiPo

## Payload Mechanism

A rack-and-pinion-based payload delivery mechanism was designed and fabricated using 3D printing technology. The mechanism converts rotational motion from a servo motor into translational motion, enabling smooth and controlled payload release while minimizing payload disturbance.

## CFD Analysis

Computational Fluid Dynamics analysis was performed using ANSYS Fluent to evaluate airflow characteristics around the UAV structure.

### CFD Parameters

* Inlet Velocity: 17 m/s
* Turbulence Model: k-epsilon
* Meshing Method: Tetrahedral Mesh
* Solver Type: Coupled Scheme
